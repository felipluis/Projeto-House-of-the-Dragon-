Projeto: House of the Dragon - Carrossel Interativo de Dragões

Como parte do meu aprendizado em Análise e Desenvolvimento de Sistemas, desenvolvi este projeto com o objetivo de aplicar conceitos de front-end e explorar integração com ferramentas modernas de geração de conteúdo. O site apresenta um carrossel interativo que exibe imagens e histórias de dragões do universo de House of the Dragon, baseando-se nas descrições detalhadas dos livros da série As Crônicas de Gelo e Fogo.

As imagens dos dragões foram criadas utilizando inteligência artificial da Microsoft, gerando designs únicos e inspirados nas características descritas nas obras literárias. No site, cada dragão possui uma seção própria, com uma ilustração e um texto explicativo, proporcionando uma experiência envolvente e informativa para os fãs.

Principais tecnologias e conceitos utilizados:

HTML, CSS e JavaScript: Para estruturar, estilizar e implementar a dinâmica do carrossel;
Design gerado por IA: Uso de ferramentas de inteligência artificial para a criação das imagens;
Responsividade: Layout adaptado para diferentes dispositivos, garantindo uma navegação fluida.
Este projeto me permitiu aprofundar habilidades técnicas e práticas, unindo programação e criatividade para criar uma experiência visual e informativa.
